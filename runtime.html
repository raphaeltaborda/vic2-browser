Windows dentro do navegador

Este teste carrega um filesystem Wine open-source e tenta iniciar o Notepad dentro do BoxedWine. Ainda não usa nenhum arquivo do Victoria II.

Teste do runtime

O primeiro carregamento pode baixar cerca de 20 MB.

Iniciar Notepad no BoxedWine

O que este teste prova

Se o Notepad abrir, teremos confirmado a cadeia navegador → WebAssembly → emulação x86 → Wine → programa Windows. Depois disso substituímos o programa de teste pelo Victoria II e passamos a investigar compatibilidade com DirectX, áudio e filesystem.
